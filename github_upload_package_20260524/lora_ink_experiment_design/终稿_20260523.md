基于LoRA微调Stable Diffusion的个性化图像生成研究

摘  要

生成式人工智能的发展推动了文本到图像生成技术在数字创作和内容生产中的广泛应用。Stable Diffusion 具有生成质量较高、开源可复现和便于本地部署等优势，但在特定风格个性化适配中，传统全量微调仍存在参数规模大、显存占用高和训练成本高等问题。针对这一问题，我的实验采用低秩适应方法对 Stable Diffusion v1\.5 进行参数高效微调。

我的实验以水墨画风格生成为实验场景，整理构建包含 2192 条图文配对记录的训练数据集，并基于 PyTorch、Diffusers、PEFT 和 Accelerate 搭建训练流程。在实验中，将 LoRA 适配器注入 Stable Diffusion v1\.5 的 UNet 模块，冻结 VAE、文本编码器和原始模型参数，仅训练新增 LoRA 参数，并围绕不同秩值和训练步数进行对比实验。模型评估方面，结合损失函数曲线、生成样例和 FID 指标，对模型收敛情况、生成质量和风格一致性进行分析。

实验结果表明，LoRA 微调能够在较低参数更新成本下学习水墨画风格特征，生成图像在风格一致性和提示词响应方面具有较好表现。研究说明，LoRA 方法能够以较少参数更新实现 Stable Diffusion 的个性化适配，为 AIGC 图像生成任务中的轻量化微调提供了可复现的实践参考。

关键词：生成式人工智能；Stable Diffusion；LoRA；参数高效微调；个性化图像生成；中国水墨画

__Research on Personalized Image Generation Based on LoRA Fine\-tuning Stable Diffusion__

<a id="_Toc13724"></a>__Abstract__

he development of generative artificial intelligence has promoted the wide application of text\-to\-image generation technology in digital creation and content production\. Stable Diffusion has advantages such as high generation quality, open\-source reproducibility, and convenient local deployment\. However, in personalized adaptation to specific styles, traditional full\-parameter fine\-tuning still faces problems such as a large parameter scale, high GPU memory consumption, and high training cost\. To address these issues, this study adopts Low\-Rank Adaptation to perform parameter\-efficient fine\-tuning on Stable Diffusion v1\.5\.

This study takes ink\-wash painting style generation as the experimental scenario, constructs a training dataset containing 2,192 text\-image paired records, and builds the training workflow based on PyTorch, Diffusers, PEFT, and Accelerate\. In the experiment, LoRA adapters are injected into the UNet module of Stable Diffusion v1\.5, while the VAE, text encoder, and original model parameters are frozen\. Only the newly added LoRA parameters are trained, and comparative experiments are conducted with different rank values and training steps\. For model evaluation, loss curves, generated samples, and the FID metric are used to analyze model convergence, generation quality, and style consistency\.

The experimental results show that LoRA fine\-tuning can learn ink\-wash painting style features with relatively low parameter update cost, and the generated images show good performance in style consistency and prompt response\. This study indicates that LoRA can realize personalized adaptation of Stable Diffusion with fewer parameter updates, providing a reproducible practical reference for lightweight fine\-tuning in AIGC image generation tasks\.

__Keywords:__ Generative Artificial Intelligence; Stable Diffusion; Diffusion Model; LoRA; Parameter\-Efficient Fine\-Tuning; Personalized Image Generation

<a id="_Toc12291"></a>__1\.1  研究背景与意义__

<a id="_Toc12330"></a>1\.1\.1 研究背景

鉴于深度学习技术以及大规模预训练模型在持续不断地向前发展，生成式人工智能AIGC已然变成了人工智能领域当中的重要研究方向，并且在文本生成、图像生成、语音合成以及多模态交互这些方面都有着很广阔的应用前景，其中文本到图像生成技术可以凭借自然语言描述去自动生成有一定语义一致性以及视觉表现力的图像，在数字艺术创作、视觉设计、文化传播以及教育展示等这些场景当中有着较高的应用价值。

在当下主流的文本到图像生成模型之中，Stable Diffusion由于有开源、能够在本地进行部署、生成质量比较高以及生态资源十分丰富等优势，已经成为学术研究和工程实践里面选用较为广泛的扩散模型之一\[1\]，跟早期生成对抗网络模型相比，扩散模型在训练稳定性、图像细节呈现以及生成多样性这些方面有着极其突出的优势。而Stable Diffusion是将扩散过程置于潜在空间当中来开展，极大程度地降低了模型训练与推理的计算开销，使得它能够在普通GPU条件下完成图像生成任务，为个性化图像生成研究提供了很不错的技术基础。

然而在实际的应用当中，通用预训练模型往往是更擅长去生成通用化、有泛化性的图像结果的，当用户期望模型能够稳定地生成某一个特定的艺术风格、特定的视觉主题或者特定的表达方式的图像的时候，仅仅依靠提示词工程的话，往往是很难去获得持续稳定而且风格统一的生成效果的，传统的全量微调方法，虽说能够提高模型对于目标风格的拟合能力，但是一般需要去更新大量的模型参数，存在着训练成本高、显存占用大、训练时间长以及硬件门槛高等问题，对于在普通实验环境当中开展研究与应用是不太适宜的。

针对该问题，参数高效微调技术慢慢受到了重视，LoRA Low\-Rank Adaptation属于一种常用的参数高效微调方法，该方法在原有权重更新过程中引入低秩矩阵，仅对少量附加参数进行训练便可以使模型适应下游任务，在维持微调效果的同时明显降低了训练成本\[38\]，就Stable Diffusion而言，把LoRA注入到UNet的相关注意力模块里，可以在冻结原始大部分参数的情况下，使模型学习特定风格特征，从而达到较低成本的个性化图像生成。实验按照该思路进行：本文选择Stable Diffusion v1\.5作为基础模型，在UNet中加入LoRA，固定原模型大部分参数，只训练少量LoRA参数，并且围绕数据准备、模型训练、图像生成、FID指标评价和可视化结果分析形成了比较完整的实验流程\[31\]。

此外，从具体研究对象来看，以中国水墨画风格作为个性化图像生成任务的目标风格，具有较好的研究代表性与实践意义。水墨画是中国传统艺术的重要表现形式，具有笔墨语言凝练、构图讲究留白、意境表达深远等显著特征，其视觉风格鲜明、艺术辨识度较高，适合作为扩散模型个性化微调的实验对象。通过利用公开中国画数据进行整理、训练和验证，并结合本地可视化界面进行结果展示，可以较为完整地验证 LoRA 微调方案在特定艺术风格生成中的可行性与实用性。

<a id="_Toc20913"></a>1\.1\.2 研究意义

本研究围绕“基于LoRA微调Stable Diffusion的个性化图像生成”展开，具有一定的理论意义、工程意义和应用意义。

从理论意义层面来讲，该实验把参数高效微调思想运用到扩散模型的个性化图像生成任务当中，去探讨LoRA在Stable Diffusion里的适配方式以及它对特定风格学习的有效性，这能够帮助拓展LoRA在视觉生成领域的应用场景，跟它在大语言模型里的广泛应用相比，LoRA在图像生成模型中的注入位置选用、超参数配置以及风格学习效果还有极大程度上的研究空间。借助对秩值、学习率、训练步数等关键因素来开展分析，可以明白参数高效微调方法在扩散模型当中的作用机制，给后续相关研究提供一定的参考\[37\]。

从工程意义这方面来看，该实验所进行的研究重点在于，凭借有限硬件条件来实现Stable Diffusion的个性化微调以及推理，有着较强的可操作性以及复现价值，项目运用PyTorch、Diffusers和PEFT等工具来构建训练以及生成流程，其中包括数据集整理、LoRA权重训练、FID 指标计算以及可视化结果分析等环节，形成了比较完整的实现路径。这种方式不依赖高端算力设备，适宜于普通GPU环境当中的实验验证，也给后续类似课题提供了可参考的技术方案\[16\]。 

从应用意义这个方面来讲，个性化图像生成可以提高生成模型针对特定风格、特定主题以及用户需求的适配能力，在数字艺术设计、文化创意传播、视觉内容生产以及智能辅助创作等这些方面有着比较强的应用前景，就拿中国水墨画风格来说，研究它在AIGC模型当中的学习与再现，能够推动传统艺术风格在智能生成场景里的数字化表达，而且有利于去探索人工智能技术跟中华优秀传统文化相结合的创新路径。运用simple\_app构建的可视化界面来展示生成结果，也让模型验证过程变得更加直观，能够体现出研究成果的可用性以及展示效果。

鉴于选用LoRA微调Stable Diffusion来开展个性化图像生成的研究工作，它回应了当下AIGC发展背景当中“高质量生成”以及“低成本适配”的现实需求，同时可以来实现推动参数高效微调技术在图像生成方面的研究和运用，有一定的理论价值、工程价值以及实际意义。

<a id="_Toc25173"></a>__1\.2  国内外研究现状__

1\.2\.1 扩散模型与 Stable Diffusion 研究现状

近年来，生成式模型在图像生成上取得快速进步，早期的生成模型主要以变分自编码器和生成对抗网络为代表，其中GAN在图像清晰度和视觉逼真度方面的表现非常突出，但存在训练不稳定、模式崩溃和生成结果的可控性不足等问题，相比之下，扩散模型通过建立正向加噪和反向去噪的过程，将图像生成任务转化为逐步实现数据分布恢复的过程，在训练稳定性、生成质量和多样性方面表现出更明显的优势，逐渐成为图像生成领域的重要研究方向\[20\]。

扩散模型的系统性发展是得益于去噪扩散概率模型的提出的，这类方法在训练阶段学习噪声预测过程，让模型能够从随机噪声逐步地来实现符合真实数据分布的图像的恢复，随着研究持续深入，相关工作从像素空间扩展到潜在空间，如此一来就有效降低了训练和推理过程当中的计算复杂度，潜在扩散模型的提出使得扩散过程不再直接在高维像素空间当中开展作用，而是把变分自编码器当作工具先将图像压缩到低维潜在表示里面，然后在潜在空间当中完成扩散与去噪，这种思路极大程度上减少了显存与算力的消耗，并且为高质量文本到图像生成提供了可行的路径。

国外对于扩散模型所开展的研究已然是相当深入的了，研究的重点渐渐从“能否生成高质量的图像”这一方面，转变为“如何提高生成的效率、条件控制的能力以及个性化适配的能力”，一方面，研究者不断对采样器、噪声调度的策略以及推理的过程进行优化，以实现生成时间的缩短以及计算成本的降低，另一方面，也有大量的研究围绕着条件控制来进行，例如借助姿态、边缘、深度图或者语义图等额外的条件，来提高模型对生成内容的可控性。此时个性化图像的生成成为了扩散模型应用的重要方向，也就是依据少量的特定风格或者特定主体的数据，让基础模型有对目标风格或者对象的学习能力，生成更符合用户需求的图像结果。

国内对于扩散模型的研究起步虽稍晚，但发展较快，相关研究主要集中在扩散模型原理分析、图像生成任务适配、与传统生成方法对比以及行业应用落地等方面\[25\]。一些研究从综述角度系统梳理了扩散模型在图像生成、图像复原和逆问题求解中的应用进展，也有部分研究围绕文本到图像生成质量提升、中文语义条件建模以及本土化场景应用开展探索。从整体上看，国内外研究普遍表明，扩散模型尤其是 Stable Diffusion 已成为当前文本到图像生成研究的重要技术基础，但其个性化能力仍高度依赖后续微调策略的设计，因此在低成本、轻量化个性化适配方面仍有较大的研究空间\[38\]。

本文在扩散模型和Stable Diffusion相关研究的基础上，把研究对象集中在具体的中国水墨画风格个性化生成场景上，不只停留在模型原理介绍或通用生成能力分析方面，一般性文本到图像生成研究主要关注文本转换为图像的过程，该实验利用Stable Diffusion v1\.5的开源特性、本地部署的方便性，形成了包括数据整理、模型微调、图像生成及结果评价在内的完整实验步骤，研究过程因此具备较好的可操作性和可复现性。同时，该实验把水墨画这种有明显视觉特点的艺术风格当作实验对象，可以更直接地看到扩散模型在特定风格学习、构图表达和视觉一致性的适配效果，这使得研究拥有更清楚的应用场景和实验目的。

1\.2\.2 LoRA 与参数高效微调研究现状

鉴于大规模预训练模型在自然语言处理以及计算机视觉任务当中的广泛运用，传统全量微调法子遭遇了训练参数规模过大、资源消耗高以及部署不灵活等问题，为去处理这些问题，参数高效微调慢慢成为了研究的热点，这种法子的核心思路是在尽可能不改动原始预训练模型参数的基础上，凭借引入少量可训练参数来实现模型对特定任务的快速适配，降低训练和存储成本，并且提高模型迁移的灵活性。

在参数高效微调这种方法当中，LoRA是运用最为广泛并且效果相对突出的一种代表方法，LoRA把权重更新给表示成两个低秩矩阵的乘积，在将原始权重冻结的这种条件之下，仅仅训练低秩分解之后新增加的参数，以此来用比较小的参数量完成模型的微调工作，起初LoRA主要是把大语言模型微调任务当作应用对象，并且在很多种下游任务上面得到了跟全量微调差不多的效果。鉴于它的实现较为简单、训练较为稳定、存储开销比较小、权重容易独立保存与加载，LoRA很快就被扩展到视觉模型以及多模态模型当中，变成了参数高效微调研究的重要方向。

在图像生成这一领域当中，围绕着Stable Diffusion的个性化微调，目前比较常见的一些方法主要有DreamBooth、Textual Inversion以及LoRA等等，DreamBooth是凭借对于模型的部分模块来开展的训练工作，使得模型能够学会特定的主体或者特定的概念，生成的效果一般是比较好的，不过训练成本相对来说是比较高的，对于显存以及训练时间的要求也是更加严格的。Textual Inversion则是凭借学习新的文本嵌入向量来表示某一个特定的概念，有着参数量小、实现比较简单的优点，但是在风格学习的深度以及复杂视觉特征表达的方面往往会存在着一定的局限\[13\]，相比较而言，LoRA在参数规模、训练效率以及生成效果之间达成了比较好的平衡，可以把基础模型原有的能力保留下来，同时又能够在比较低的资源消耗之下来实现特定风格或者特定主体的学习，在Stable Diffusion个性化微调当中获得了广泛的关注。

目前国外关于LoRA在扩散模型中应用的研究主要集中在三个方向：一是对LoRA注入的位置进行选择，例如将其加入到UNet的各个注意力层、卷积层、文本编码器模块，以分析不同位置对生成效果产生的影响，二是超参数设置问题，其中主要原因包括秩值、缩放系数、学习率、训练步数等对微调性能产生的作用，三是将LoRA与其他微调方式结合使用，如多LoRA叠加、风格融合和模块化切换，从而提高个性化生成的灵活性和可扩展性。国外研究已经证明LoRA是适合用于扩散模型轻量化微调的有效方法，不过在不同任务、不同数据规模、不同风格场景下，它的最佳配置仍然需要通过实验来验证。

国内在参数高效微调方向的研究同样逐步增多，尤其是在大模型轻量化部署和低成本适配需求推动下，LoRA 已被广泛关注。相关研究主要聚焦于 LoRA 数学原理分析、参数规模优势、在视觉任务中的迁移能力以及与其他轻量化方法的比较等方面。在 Stable Diffusion 个性化生成场景中，国内已有部分研究开始将 LoRA 应用于特定风格图像生成、人物形象定制和垂直领域视觉内容生成，但整体上仍以工程实践和应用探索为主，针对“具体注入策略—训练配置—生成效果”之间关系的系统实验分析仍相对不足\[37\]。

从已有的研究情况来看，LoRA给Stable Diffusion的个性化图像生成这方面，提供了一种能把训练效率以及生成效果都兼顾到的可行办法，不过还是有一些问题值得去研究一下：第一点，在不同的目标风格当中，LoRA的最优注入模块还有秩值设置并不是统一的，第二点，在小样本的条件之下，模型是不是容易出现风格学习不够或者过拟合的问题，还得去验证，第三点，怎样在保证训练成本比较低的把图像语义一致性、风格稳定性以及生成细节质量给提升上去，这还是当前研究的重点所在。鉴于此，围绕着LoRA微调Stable Diffusion来开展实验研究，去分析关键超参数对生成效果的影响，并且结合特定的艺术风格数据集来进行验证，是有着比较强的研究价值还有实践意义的，该实验就是在这样的背景之下展开的，训练脚本里面借助向UNet注入LoRA、冻结主体参数，并且围绕rank、learning rate以及max\_train\_steps等配置来开展实验，这和上述的研究趋势也是相契合的\[14\]。

在对LoRA和参数高效微调进行研究的基础上，本文实验的主要优势是对具体的微调过程和实验配置进行了分析，该实验表明LoRA能够降低训练成本，同时也结合Stable Diffusion v1\.5的UNet结构，将LoRA适配器注入到相关模块中，并冻结VAE、文本编码器和原始主体网络参数，只训练少量新增参数，从而减少显存占用和训练开销。该实验对比了Rank值、学习率和训练步数等重要参数，并且通过损失函数曲线、生成样例和FID指标来分析模型表现，使LoRA微调效果不再仅限于主观展示，而是形成了比较完整的实验验证过程，该设计能够更清楚地说明LoRA在普通硬件条件下进行个性化图像生成是可行的，并且为后续类似风格迁移和轻量化微调任务提供了参考。

1\.2\.3 现有研究的不足与该实验研究切入点

综合国内外的研究状况能够看出，扩散模型Stable Diffusion，已经拥有了为文本到图像生成开展基础框架构建的成熟能力，而像LoRA等参数高效微调方法，也给个性化生成任务的轻量化实现路径提供了支持，不过，现有的研究还是存在着一些不足的地方。

<a id="_Toc32558"></a>部分研究主要关注模型原理介绍或通用能力验证，对具体风格场景下的实验过程、数据处理流程及参数配置分析不够细致，使研究结果的可复现性和可借鉴性受到一定影响，不同研究在评价方式上差异较大，有些仅展示可视化结果而缺乏定量指标支持，部分研究侧重定量结果，但风格学习效果和实际应用分析不充分，就具体应用上，多数研究主要关注大规模模型性能的提高，但较少考虑普通GPU环境下可实现性和可部署性。这不利于相关技术在教学实验和轻量化场景中的推广，该实验选择中国水墨画风格个性化生成作为研究对象，使用Stable Diffusion v1\.5和LoRA形成轻量化微调方案，通过整理数据、训练模型、生成图像、评估FID指标、可视化对比生成结果、展示本地界面等方式，对个性化图像生成流程进行了整体实现和分析。本文在分析模型原理的同时，也更关注利用具体的实验步骤来检验LoRA在特定风格生成任务里是否可以使用，从而为Stable Diffusion的低成本个性化适配提供实践依据。

<a id="_Toc28932"></a>__2  相关理论基础__

<a id="_Toc25684"></a>__2\.1  扩散模型的核心原理__

<a id="_Toc2593"></a><a id="_Toc9099"></a>扩散模型，是属于那种基于概率来产生想法的深度生成模型，它的核心要点，就是运用“一步步地加噪”以及“一步步地去噪”这两个完全相反的过程，来达成从真实数据分布朝着噪声分布，然后再从噪声分布恢复到真实数据分布的建模相关工作，跟传统的生成对抗网络相比的话，扩散模型有训练过程更加稳定、生成图像质量较高、模式覆盖更为全面等优点，在图像生成这个领域当中就得到了广泛的关注。

<a id="_Toc8484"></a><a id="_Toc19185"></a>扩散模型一般是由正向扩散过程以及反向扩散过程来组成的，正向扩散过程运用马尔可夫链一步一步地往原始图像当中去添加高斯噪声，致使它最后去逼近标准高斯分布，反向扩散过程，就是让神经网络来学习这一加噪过程的逆变换，从纯噪声开始一步一步地进行恢复出目标图像，模型训练的主要原因囊括学习在不一样时间步之下的噪声预测能力，以此来实现高质量图像生成。

<a id="_Toc29690"></a>__2\.4  参数高效微调的核心思想__

参数高效微调（Parameter\-Efficient Fine\-Tuning, PEFT）的核心目标，是在尽可能少地更新预训练模型参数的前提下，实现模型对特定下游任务的快速适配。随着预训练模型参数规模不断增大，传统全量微调方式面临训练成本高、显存占用大、权重文件庞大以及多任务部署不灵活等问题。PEFT 方法正是在这一背景下提出，并逐渐成为大模型微调的重要技术路线。

从实现方式上看，参数高效微调方法通常不直接修改原始模型的全部参数，而是通过引入少量附加结构、可学习提示向量或结构化参数更新，实现对任务特征的建模。常见方法包括 Adapter Tuning、Prefix Tuning、Prompt Tuning 以及 LoRA 等。其中，Adapter Tuning 通过在网络中插入小型瓶颈层来实现任务适配；Prefix Tuning 和 Prompt Tuning 通过引入可学习的前缀或提示向量来调节模型输出；LoRA 则通过低秩矩阵分解的方式，对权重更新量进行近似表达，从而以更低成本完成模型微调。

相较于其他参数高效微调手段而言，LoRA有数个相对较为较大的优势，它对原始模型结构所实施的改动较小，实现的办法简洁，非常容易同现有的模型框架开展结合，，LoRA训练所获取的权重文件体积较小，便于存储、传输以及加载，另外，不同任务或者不同风格所对应的LoRA权重能够与同一基础模型灵活地搭配起来，如此一来让模型在多风格、多任务的情境当中拥有较强的扩展性。

<a id="_Toc2636"></a>__3\.1  数据集构建与预处理__

<a id="_Toc15125"></a>3\.1\.1 数据集主题选择

<a id="_Toc26975"></a>为验证 LoRA 微调 Stable Diffusion 在特定艺术风格个性化生成任务中的有效性，该实验选择水墨画风格作为实验对象。该类图像在构图、用墨、留白和意境表达等方面具有较强辨识度，适合作为个性化图像生成任务的目标风格。与普通自然图像和通用插画风格相比，水墨画风格更能体现模型对特定视觉特征的学习效果；同时，围绕传统艺术风格开展实验，也能够体现人工智能技术在文化数字化表达中的应用价值。

<a id="_Toc24774"></a>因此，该实验以水墨画风格作为实验对象，既能够突出个性化图像生成的研究重点，也便于观察模型对目标风格特征的学习能力和生成稳定性。

<a id="_Toc26414"></a>3\.1\.2 数据集收集与具体来源

该实验实验所用数据集来源于 Hugging Face 平台上的公开中国画图文数据集 zqman/Text2image\-ChinesePainting。该数据集以中国画图像及其对应文本描述为主要内容，属于图文配对数据资源，能够为文本到图像生成模型的风格微调提供基础数据支持。经过整理与检查后，该实验训练集共包含 2192 张图像，metadata\_train\.jsonl 中对应 2192 条图文配对记录。数据检查结果表明，元数据记录与图像文件能够正确对应，未发现图像文件缺失情况，样例图片也能够正常打开，说明数据集具备较好的完整性和可用性。

从数据内容来看，该数据集样本主要围绕中国画相关视觉内容展开，涉及山水、花鸟、人物等常见中国画题材，图像整体具有较明显的传统绘画风格特征。其配套文本描述能够为模型训练提供语义条件，使模型在学习图像风格特征的同时，建立文本提示词与视觉内容之间的对应关系。因此，该数据集与该实验基于 LoRA 微调 Stable Diffusion 实现中国画/水墨画风格个性化生成的研究目标具有较高契合度。

<a id="_Toc29646"></a>3\.1\.3 数据预处理

为使数据满足 Stable Diffusion v1\.5 的 LoRA 微调要求，该实验对中国画图文数据进行了统一检查与预处理。首先，对图像文件与元数据记录进行一致性检查，确认 metadata\_train\.jsonl 中共包含 2192 条图文配对记录，且对应图像文件均未缺失。其次，对样例图像进行打开测试，确认图像文件能够正常读取，避免损坏文件影响后续训练过程。

在训练输入方面，图像会在训练过程中被统一转换为 RGB 格式，并按照 Stable Diffusion v1\.5 的输入要求处理为 512×512 分辨率；文本描述则作为提示词输入 tokenizer 和文本编码器，用于生成文本条件特征。通过上述处理，该实验构建了适用于 LoRA 微调实验的图文配对训练集，为后续不同 Rank 值和训练步数配置下的对比实验提供统一的数据基础。

<a id="_Toc31203"></a>__3\.3  LoRA微调的模型实现__

<a id="_Toc28259"></a>3\.3\.1 预训练模型加载

该实验选择 Stable Diffusion v1\.5 作为基础模型，并围绕其 UNet 模块开展 LoRA 微调。根据训练脚本，模型加载时分别从预训练模型目录中读取 tokenizer、text encoder、VAE、UNet 和 scheduler 等组件，并将其组装为完整的训练框架。

<a id="_Toc4442"></a><a id="_Toc27584"></a>把Stable Diffusion v1\.5当作选用的缘由，一方面是鉴于这个模型的结构成熟、生态完善，相关资料也是丰富的，方便去开展实验复现的工作，另一方面，这个版本在文本到图像生成任务方面有较好的基础生成功能，能够以实现为后续个性化风格微调提供稳定的预训练起点。

<a id="_Toc19141"></a>3\.3\.2 LoRA 适配器注入

在模型微调阶段，该实验没有将全量微调方式视为更新所有参数的方法，而是仅将LoRA结构注入到UNet中，并且冻结了原始主体参数，根据训练脚本，VAE、text encoder和UNet的原始参数均被设置为不参与训练，只有新增的LoRA参数作为优化对象参与更新。

具体实现上，训练脚本通过 LoraConfig 定义 LoRA 的关键配置，包括 rank、lora\_alpha、target\_modules 和 lora\_dropout 等参数，然后调用 unet\.add\_adapter\(\) 将 LoRA 注入到指定模块中。该实现方式能够在尽量不改变原始模型结构的前提下，使模型具备学习新风格特征的能力。

这种实现方案的优点在于，训练阶段实际更新的参数数量较少，既降低了显存占用，也减少了训练时间；同时，训练完成后得到的 LoRA 权重可以独立保存，并在推理阶段灵活加载到基础模型上，具有较好的可扩展性。

<a id="_Toc3201"></a>3\.3\.3 训练数据组织与输入构造

为了适配 Stable Diffusion 的训练要求，项目中定义了基于 JSONL 元数据的图文数据集类。训练时，程序会根据 metadata\_train\.jsonl 文件读取图像路径与对应文本描述，并对图像执行缩放、裁剪、随机翻转、归一化等变换操作；同时，对文本提示词进行 tokenization，生成模型训练所需的输入张量。

这种设计方式使训练流程具有较好的规范性和自动化程度。一方面，图像增强可以提高模型对样本变化的适应能力；另一方面，通过统一的数据读取和文本编码流程，可以确保训练数据格式稳定，减少人工处理带来的误差。

<a id="_Toc16001"></a>3\.3\.4 模型训练过程

在开展训练的过程当中，首先是运用VAE把输入图像去编码成为潜在变量，接着由文本编码器把提示词去编码成为文本特征，然后，训练脚本从标准高斯分布里边去采样噪声，并且随机生成时间步，把噪声添加到潜在变量当中，以此来构造扩散模型训练所需要的含噪样本，UNet在文本条件引导之下对噪声开展预测，并且凭借均方误差损失去计算预测噪声跟真实噪声之间的差异，达成参数的更新。

<a id="_Toc23569"></a><a id="_Toc16212"></a>在优化策略当中，训练脚本选用了AdamW优化器，并且将其和梯度累积、梯度裁剪以及自动混合精度这些技术一起运用，以实现训练稳定性的提高以及资源利用效率的提升，在训练过程里，程序会定期去处理记录loss的工作，并且把训练日志保存为CSV文件，那么就能在后续开展绘制损失曲线以及分析训练趋势的工作。

<a id="_Toc17170"></a>3\.3\.5 权重保存与中间结果输出

为了能够去对训练过程开展跟踪工作以及后续对模型进行调用，项目在训练这个阶段当中会定期去进行LoRA中间检查点的保存工作，并且在训练结束以后来实现最终LoRA权重的导出，保存的内容包含了\.safetensors格式权重文件以及简化配置文件，并且还会自动地产生训练过程摘要文件，当中记录了训练步数、学习率、rank以及批次参数等关键信息。

除此之外，训练脚本还有在训练完成之后基于验证提示词来自动生成一些样例图像的功能，用来快速看看模型训练的效果，这种设计能够把“训练过程监控”以及“结果可视化验证”这两方面结合起来，提升实验分析的效率。

<a id="_Toc1316"></a>__3\.4  图像生成与对比实验设计__

<a id="_Toc30526"></a>3\.4\.1 图像生成实现

<a id="_Toc22380"></a><a id="_Toc22713"></a>在模型完成训练之后，该实验运用独立的生成脚本，去开展加载Stable Diffusion基础模型以及训练所获LoRA权重的工作，依靠输入提示词来实现图像的生成，生成脚本拥有单条提示词输入、多条提示词文件输入以及配置文件驱动的批量生成等功能，并且可以借助命令行来覆盖输出路径、推理步数、引导系数以及随机种子等参数。

<a id="_Toc31822"></a>3\.4\.2 对比实验思路

为了分析 LoRA 微调中关键超参数对模型生成效果的影响，该实验围绕 rank、learning rate 和 max train steps 等参数开展对比实验。之所以选择这几个因素，主要是因为它们直接影响模型可训练参数规模、风格学习能力、收敛速度和过拟合风险。训练脚本本身也对这些参数提供了命令行覆盖接口，便于在统一代码框架下进行不同配置的实验比较。

这里的秩直接表示LoRA低秩矩阵的特征拟合能力，秩设置过小会使模型不能充分捕捉目标风格的主要特性，秩过大则会明显增加训练参数量和计算资源开销，学习率决定模型参数迭代更新的步长，直接影响到训练过程的稳定性和收敛效率，学习率较低会大幅度延长收敛周期，较高则容易引起训练过程震荡发散，最大训练步数代表训练迭代的完成程度，步数不够时风格特征学习通常不完整，步数超过合理范围会出现过拟合问题，对上述三类主要参数进行对比分析，可以比较完整地展示LoRA微调过程的训练变化和最终生成效果。

从移动平均曲线来看，各组实验在训练初期均出现较快下降，随后基本维持在一定范围内波动，没有出现持续发散的情况。这说明 LoRA 微调过程整体是可训练的，模型能够在冻结 Stable Diffusion 主体参数的基础上，通过新增的 LoRA 参数逐步学习水墨画风格特征。由于扩散模型训练本身具有较强随机性，因此本文不以单个 step 的 loss 高低作为判断模型优劣的唯一依据，而是结合移动平均趋势、生成样例和 FID 指标进行综合分析。

在Rank=8、step=1200 的实验中，移动平均 loss 在训练初期快速下降，随后长期处于波动状态，整体未出现明显发散，说明较低 Rank 设置已经具备一定的风格学习能力。Rank=16、step=600 的实验训练步数较短，曲线在前期下降后仍保持波动，说明模型完成了初步训练，但对后续训练阶段的变化观察相对有限。

Rank=16、step=1200 的实验与 Rank=8、step=1200 具有相同训练步数，二者曲线形态较为接近，均表现为原始 loss 波动明显、移动平均 loss 相对稳定的特征。相比 Rank=8，Rank=16 具有更高的参数表达能力，但从损失曲线本身来看，其优势并不是简单表现为 loss 持续下降，还需要结合后续生成效果和 FID 结果进一步判断。

当实验的rank等于16且步数为1800时，训练过程得到了延长，从曲线中可以看到，训练步数增加，移动平均 loss 仍然存在周期性波动，没有因为训练步数增加而完全变得平滑，这表明增加训练步数可以让模型获得更充分的优化机会，但是无法消除扩散模型训练中出现的随机波动。

Rank=32、step=1200 的实验中，移动平均 loss 同样维持在一定区间内波动，整体趋势与 Rank=8 和 Rank=16 的 1200 步实验较为接近。这表明在当前实验条件下，单纯提高 Rank 并不会直接带来更平滑的 loss 曲线，也不能仅凭 Rank 增大就判断模型训练效果更优。

<a id="_Toc31013"></a>__4\.6 未微调Stable Diffusion基础模型的生成效果对比__

为了检验LoRA微调对水墨画风格适配产生的影响，本文在相同的提示词、随机种子和推理参数条件下，对比未微调Stable Diffusion基础模型与LoRA微调模型的生成结果，实验选取水墨山水、花鸟画和古风人物这三类典型提示词，用来观察两类模型在语义响应和风格表达上的差异。

从生成结果来看，未微调 Stable Diffusion 基础模型能够较好响应提示词中的主体内容，例如山体、水面、梅枝、鸟类、人物和古琴等元素，说明基础模型本身具有较强的通用文本到图像生成能力。但其生成结果整体更接近通用数字插画或普通古风图像，在笔墨层次、宣纸质感、留白构图和传统绘画氛围方面表现不足。

对比之下，LoRA微调模型在维持提示词语义响应功能的同时，加强了水墨画风格的呈现，在山水场景中，生成的图像里山体的轮廓、雾气的过渡和留白的关系更加接近传统水墨山水画，在花鸟场景里，枝干笔触、灰阶背景和画面疏密关系都比较符合传统花鸟画特点，在人物场景中，生成结果表现为明显的宣纸底色、传统设色和古画氛围。由此可知，LoRA微调不是简单地改变生成内容，而是要在保留基础模型语义生成能力的前提下，提高它对目标艺术风格的适配能力，总体来说，未进行微调的基础模型可以完成基本的文本到图像生成任务，不过在水墨画风格表达上会有不足，经过LoRA微调，模型在山水、花鸟和人物等典型场景中都表现出更强的传统绘画风格特征，主要因为LoRA微调可以有效提高Stable Diffusion在特定艺术风格生成任务中的表现。

<a id="_Toc11982"></a>__4\.9 实验结论__

首先，从训练过程来看，五组 LoRA 微调实验均能够正常完成训练。虽然原始 loss 曲线存在明显波动，并在部分 step 处出现尖峰，但移动平均曲线整体保持在相对稳定区间内，未出现持续发散现象。这说明在当前实验条件下，LoRA 微调能够在冻结 Stable Diffusion 主体参数的基础上，通过训练新增低秩适配参数学习水墨画风格特征。

其次，从 Rank 对比结果来看，在训练步数同为 1200 的条件下，Rank=8、Rank=16 和 Rank=32 均能够完成有效训练，但提高 Rank 并未直接带来更稳定的 loss 曲线。结合 FID 结果可知，Rank=8、step=1200 的 FID 为 365\.7302，优于 Rank=16、step=1200 和 Rank=32、step=1200，说明 Rank 并不是越大越好，仍需结合实际生成效果和评价指标进行选择。

再次，从训练步数对比来看，在固定 Rank=16 的条件下，step=600、step=1200 和 step=1800 均表现出一定训练效果。其中 Rank=16、step=600 的 FID 最低，为 356\.3228，说明适度训练已经能够取得较好的图像分布接近效果，继续增加训练步数并不必然带来更优结果。

从学习率对比来看，、和三组学习率下模型均能正常生成水墨风格图像。其中，在风格表现、主体完整性和画面协调性之间相对均衡，因此可作为本文实验中较合适的学习率设置。

最后，从生成结果来看，LoRA 微调后的模型相比未微调基础模型具有更明显的水墨画风格特征。生成图像在墨色层次、留白构图、山水元素和传统绘画氛围方面更接近训练集样本，但在局部细节、复杂结构组织和笔墨自然度方面仍存在不足。

综上所述，本文实验表明，LoRA 微调能够有效提升 Stable Diffusion 对水墨画风格的适配能力，并在较低参数更新成本下实现个性化图像生成。基于当前实验结果，Rank=16、step=600、学习率的配置在 FID 指标和生成效果上表现较为均衡，可作为本文实验条件下的较优配置。

<a id="_Toc15689"></a>__5  个性化图像生成系统设计与实现__

<a id="_Toc16258"></a><a id="_Toc14694"></a>鉴于前文完成了模型训练、实验分析以及生成结果对比，该实验运用本地可视化界面，来进行对训练后的个性化图像生成模型的应用展示工作，本章的重点并非界面文件本身，而是凭借PyTorch与Diffusers函数库来实现模型加载、LoRA权重挂载、提示词输入以及图像生成输出的完整调用流程，同时借助桌面图形化界面把模型推理结果直观地展示出来。这种展示方式可以验证该实验训练所得到的LoRA权重的可用性，也能够更为清晰地呈现个性化图像生成系统的实际应用效果。

<a id="_Toc1097"></a>__5\.1 个性化图像生成界面的设计目标__

为了去实现论文研究成果可展示性的提升，该实验在模型训练以及推理脚本的基础之上，选用了设计这种方式，并以实现一个本地桌面可视化界面为目标，来实现完成提示词输入、参数设置、图像生成以及结果保存这些基本操作，这个界面的设计目标主要是体现在以下的方面当中。

首先，界面要能够把文本到图像生成的基本流程直观地呈现出来，让用户可以直接把提示词输入进去就触发图像生成，而不用依靠命令行去执行脚本，其次，界面得和前面模型训练的结果契合，也就是在推理阶段把Stable Diffusion基础模型以及训练完成的LoRA权重调用起来，这样就能保证展示结果和论文实验过程是一致的。再次，界面要拥有提供必要推理参数调节能力，像生成步数、Guidance还有随机种子等等，来提高实验展示的完整性以及可控性，最后，界面还应该有支持结果图像显示和保存的功能，方便观察不同提示词所对应的生成效果，并且为后面实验截图、样例整理以及论文插图提供支持。

总体而言，该界面在该实验中的作用主要是服务于研究成果展示，而不是构建复杂的软件系统。其目标是将模型调用过程简洁、清晰地呈现出来，使个性化图像生成从“脚本级运行结果”转化为“可交互、可观察的应用形式”。

<a id="_Toc5712"></a>__5\.2 基于 PyTorch 与 Diffusers 的模型调用实现__

该实验个性化图像生成界面的底层推理流程，仍然建立在第3章所述训练与生成脚本基础之上。系统首先加载 Stable Diffusion 基础模型，再挂载训练完成的 LoRA 权重，并根据用户输入的提示词执行图像生成。根据项目中的生成脚本，推理阶段主要使用 StableDiffusionPipeline\.from\_pretrained\(\) 完成模型加载，并通过 load\_lora\_weights\(\) 将 LoRA 权重融合到基础模型中。

在实际的调用过程当中，界面所开展的工作主要是对已有的推理逻辑去进行图形化的封装工作，用户在界面当中输入提示词以及负面提示词，并且把步数、Guidance和种子设置好之后，系统就会把这些参数运用到模型推理流程当中，紧接着完成图像的生成工作并且把结果返回至界面的显示区域，界面还拥有把当前生成结果保存到本地的功能，以便后续的样例整理以及实验记录。从这当中就能够看出，这个界面并不是独立于论文实验流程之外的全新系统，而是把已有的模型推理逻辑运用到应用化以及可视化方面来实现的。

<a id="_Toc10349"></a>5\.3\.1 提示词输入模块

界面顶部设置了提示词输入区域，用于输入图像生成所需的文本描述。从当前系统截图来看，提示词输入框已经支持较长文本输入，例如可以输入“traditional Chinese ink wash landscape, misty mountains, river, lone boat, elegant brushwork”等描述性语句。该模块是整个系统的输入起点，直接决定模型生成图像的主题内容和整体风格方向。

在该实验所做的研究任务里面，提示词不光是承担“描述画什么”的作用，而且还承担“对生成风格限定”的作用，在实际运用时，提示词一般同时有题材要素以及风格要素，比如山水、江面、小舟、云雾、松树等内容词，还有traditional Chinese ink wash、brushwork等风格词，这个模块的存在说明该实验的研究对象仍旧属于很典型的文本到图像生成任务，而不是图像编辑任务。

<a id="_Toc4320"></a>5\.3\.2 负面提示词模块

在提示词输入区域下方，界面进一步设置了负面提示词输入框。从当前截图可见，系统中已经填写了 “low quality, blurry, distorted anatomy, watermark, text, oversaturated” 等内容。该模块用于抑制生成图像中不希望出现的特征，从而在一定程度上提高输出质量和画面纯净度。

对于该实验所研究的水墨画风格生成任务而言，负面提示词模块具有较强实用意义。由于模型生成过程中可能出现模糊、水印、文字残留或局部失真等问题，因此通过在推理阶段加入负面约束，可以帮助模型减少不必要的低质量视觉成分，使生成图像更加接近论文所需的展示效果。

<a id="_Toc15301"></a>5\.3\.3 参数设置模块

在输入区域下方，界面设置了参数控制部分，主要包括“步数”“Guidance”和“种子”三个字段。当前示例中，步数设置为 24，Guidance 设置为 7\.5，种子设置为 42，说明系统已具备对关键推理参数进行基础配置的能力。

当中步数参数主要是用来开展决定扩散模型反向去噪过程迭代次数的工作的，对于图像生成质量以及推理时间都会产生影响，Guidance参数是拿来进行控制文本条件对生成图像约束强度的工作的，要是数值适宜的话能够提高图像跟提示词之间的语义一致性，种子参数是用来进行控制随机性的工作的，便于来实现实验结果的复现并且比较不同提示词或者参数条件之下的生成差异。虽然这些参数并非该实验训练阶段的核心变量，但是在应用展示阶段，它们能够极大程度上提升系统的可调节性以及实验可重复性。

<a id="_Toc327"></a>5\.3\.4 生成与保存模块

在参数区域的右侧，界面当中设置了“生成图片”以及“保存当前图”这两个按钮，在这当中，“生成图片”按钮是拿来触发模型推理的流程，“保存当前图”按钮则是用于把当前生成的结果保存到本地，这样的设计让系统拥有了从输入到输出再到结果留存的完整功能链条，

该模块在系统交互流程中承担核心作用。“生成图片”按钮对应模型推理过程，体现了系统从提示词输入到图像生成的基本功能；“保存当前图”按钮则用于保留生成结果，便于后续实验样例整理、结果对比和论文展示。因此，该模块虽然功能结构较为简洁，但保证了系统输出结果的可复现、可保存和可展示。

<a id="_Toc17762"></a>5\.3\.5 状态提示与结果展示模块

在按钮下方这个地方，界面它有“生成完成，”这样的状态提示语句给展示出来了，这就说明了系统可以去处理当前推理过程相关的工作，然后给到基本的反馈，在这之下，界面的中央是图像展示区域，是拿来展示模型生成结果的，就从截图这个方面来看，生成的图像可以直接就呈现在界面当中，而且显示的效果很清晰，能够很直观地把当前提示词条件下的推理结果给反映出来。

<a id="_Toc17825"></a><a id="_Toc266"></a>这一部分，是整个界面的核心输出模块，同时也是该实验应用展示当中非常重要的内容，运用结果展示区，用户可以来进行输入提示词以及输出图像这两者之间对应关系的直接观察，并且去处理判断生成结果是不是契合预期风格以及内容方面要求的工作，对于论文而言，这个模块的意义可是“把图显示出来”这么简单，而是它能够直观地证明该实验训练得到的LoRA权重已经拥有了实际调用的功能。

<a id="_Toc32739"></a>__5\.4 本章小结__

本章围绕基于 PyTorch 与 Diffusers 函数库的个性化图像生成应用展示展开，结合当前实际界面，介绍了系统的设计目标、模型调用流程以及功能模块构成。通过设置提示词输入、负面提示词、步数、Guidance、种子等参数，并结合“生成图片”和“保存当前图”等操作，系统实现了对训练后 LoRA 模型的可视化调用，使该实验研究成果能够以更加直观的形式展示出来。

从界面所呈现出来的效果去看的话，系统已经能够借助输入提示词，来生成有中国水墨山水画风格特性的图像了，这也就意味着训练所得到的LoRA权重在实际推理当中是有可用性的，虽然说目前系统在图像细节质量以及功能完整性这些方面还是存在着一定程度的不足，但是它已经达成了从模型训练、推理调用一直到可视化展示的基本闭环，给全文研究成果的总结以及后续展望给予了良好的基础。

<a id="_Toc32272"></a>__6  总结与展望__

<a id="_Toc8925"></a>__6\.1 研究总结__

本文围绕“基于 LoRA 微调 Stable Diffusion 的个性化图像生成研究”展开，针对传统全量微调训练成本高、显存占用大、硬件要求较高等问题，将 LoRA 参数高效微调方法应用于 Stable Diffusion v1\.5，并以中国水墨画风格图像生成为实验场景，完成了数据集构建、模型微调、图像生成、结果评价和可视化展示等工作。

在实验实现方面，本文基于公开中国画图文数据集整理得到 2192 条图文配对记录，并使用 PyTorch、Diffusers、PEFT 和 Accelerate 等工具搭建训练流程。训练过程中，将 LoRA 适配器注入 Stable Diffusion v1\.5 的 UNet 模块，冻结 VAE、文本编码器和原始模型主体参数，仅训练新增 LoRA 参数，从而降低了模型微调的参数更新成本和显存压力。

在实验分析方面，本文围绕 Rank 值、训练步数和学习率等因素进行了对比实验。结果表明，不同配置下的 LoRA 模型均能够完成正常训练，虽然 loss 曲线存在一定波动，但整体没有出现持续发散现象，说明 LoRA 微调在当前任务中具有可训练性。FID 结果显示，Rank=16、step=600 的实验组取得最低 FID，Rank=8、step=1200 的结果也较为接近，说明 Rank 和训练步数并不是越大越好，需要结合生成效果和评价指标综合判断。

从生成结果来看，LoRA 微调后的模型相比未微调 Stable Diffusion 基础模型，能够生成更明显的水墨画风格图像。生成结果在墨色层次、留白构图、山水元素和传统绘画氛围方面更接近训练集样本，说明模型已经学习到一定的目标风格特征。但在局部细节、复杂结构组织和笔墨自然度方面，生成结果仍存在不足。

此外，本文还构建了本地可视化图像生成界面，实现了提示词输入、参数设置、图像生成和结果保存等功能，验证了训练后 LoRA 权重在实际推理过程中的可用性。总体来看，本文实验表明，LoRA 微调能够在较低训练成本下提升 Stable Diffusion 对水墨画风格的适配能力，为个性化图像生成任务提供了一种可复现的实现路径。

<a id="_Toc9192"></a>__6\.2 研究不足__

本文虽然完成了较完整的实验流程，但仍存在一些不足。首先，实验数据虽然包含 2192 条图文配对记录，但数据类型主要集中在中国画和水墨画风格，题材覆盖范围仍有限，对复杂场景、多主体图像和不同绘画流派的学习能力还有待提升。

其次，本文的参数实验范围仍不够全面。虽然已经比较了 Rank 值、训练步数和学习率对模型表现的影响，但对于 LoRA 注入位置、lora\_alpha、dropout、批次大小、推理步数和 Guidance Scale 等因素，尚未进行系统消融实验。因此，当前得到的较优配置只能说明其在本文实验条件下表现较好，不能直接视为全局最优方案。

再次，本文的评价方式仍有一定局限。FID 能够从图像分布层面评价生成图像与真实图像的接近程度，但本次每组实验参与计算的生成图像数量较少，结果容易受到样本选择和生成随机性的影响。同时，本文对语义一致性、风格相似度和主观视觉质量的量化评价仍不充分，后续还需要引入更多指标进行综合分析。

最后，本文构建的可视化界面主要用于实验展示，功能较为基础，尚未形成完整的图像生成应用系统。在多图生成、历史结果管理、参数模板保存和模型权重切换等方面仍有进一步完善空间。

<a id="_Toc10784"></a>__6\.3 未来展望__

后续研究可以首先从数据集扩展入手，引入更多高质量水墨画和中国画图像，并增加山水、花鸟、人物、建筑等不同题材样本，以提升模型对多样化风格和复杂视觉元素的学习能力。

其次，可以进一步开展更系统的参数消融实验。未来可围绕 Rank、训练步数、学习率、LoRA 注入模块、alpha 参数和 dropout 等因素进行组合实验，并结合 FID、CLIP Score、LPIPS 和人工评分等指标，对不同配置下的生成效果进行更全面的评价。

再次，可以将本文方法推广到更多个性化生成任务中，例如工笔画、剪纸、动漫风格、人物形象定制和产品设计图像生成等场景，从而进一步验证 LoRA 微调方法在不同风格任务中的适用性。

在应用方面，后续可以继续完善本地可视化系统，增加多图对比、历史记录、参数模板、提示词推荐和 LoRA 权重切换等功能，使系统从实验展示工具逐步扩展为更实用的轻量化图像生成应用。

总体而言，本文验证了 LoRA 微调 Stable Diffusion 在水墨画风格个性化生成任务中的可行性。虽然当前研究在数据规模、参数实验和评价体系方面仍有不足，但已经完成了从数据准备、模型训练、结果分析到界面展示的基本闭环，为后续进一步研究提供了实践基础。
