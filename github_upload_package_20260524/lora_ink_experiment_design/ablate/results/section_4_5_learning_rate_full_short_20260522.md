# 4.5 不同学习率对训练表现的影响分析

为了分析学习率对 LoRA 微调训练表现的影响，本文在大训练集条件下重新设置学习率消融实验。本组实验使用 `data/ink_painting_2192` 数据集，共 2192 张水墨图像，并固定 Rank=16、训练步数为 1200、随机种子为 42。三组实验除学习率不同外，其余训练参数保持一致，分别比较 1e-4、2e-4 和 5e-4 三组学习率下的训练结果。

## 4.5.1 不同学习率的真实训练结果

表4-5 不同学习率下的训练结果对比

| 学习率 | Rank | 训练步数 | 最终 loss | 日志中最低 loss | 最低 loss 对应步数 | 后100步平均 loss | FID↓ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1e-4 | 16 | 1200 | 0.231827 | 0.005093 | 452 | 0.155495 | 342.1240 |
| 2e-4 | 16 | 1200 | 0.231671 | 0.005074 | 452 | 0.155390 | 395.1786 |
| 5e-4 | 16 | 1200 | 0.231410 | 0.005075 | 452 | 0.155298 | 386.7016 |

从最终 loss 看，三组实验结果非常接近。学习率为 5e-4 时最终 loss 最低，为 0.231410；2e-4 的最终 loss 为 0.231671；1e-4 的最终 loss 为 0.231827。三者之间差距很小，说明在当前大训练集和 1200 步训练条件下，这三组学习率都能够正常完成训练，没有出现明显发散现象。

从训练过程中的最低 loss 看，1e-4、2e-4 和 5e-4 的最低 loss 分别为 0.005093、0.005074 和 0.005075，并且最低 loss 都出现在 step=452。这说明不同学习率下模型都能在训练中期进入相近的低损失区域，单纯从最低 loss 来看，三组学习率之间没有明显差距。

从后 100 步平均 loss 看，5e-4 的数值最低，为 0.155298；2e-4 为 0.155390；1e-4 为 0.155495。这说明较高学习率在本组实验中略微降低了后期平均 loss，但这种差距仍然很小，不能说明 5e-4 在生成质量上一定最好。

## 4.5.2 不同学习率下 loss 曲线的真实差异

从 loss 曲线形态来看，三组实验整体走势非常接近，都是在训练过程中不断出现局部下降和反弹。与小样本实验相比，大训练集条件下训练步数增加到 1200 步，模型有更长时间接触不同训练样本，但 loss 曲线仍然存在明显波动。这说明扩散模型的随机噪声采样、batch 差异以及图像内容复杂度仍会对单步 loss 产生影响。

具体来看，1e-4、2e-4 和 5e-4 在许多关键位置上的 loss 变化都比较接近，例如三组实验都在 step=452 附近达到最低 loss。这表明当前学习率范围内，学习率变化并没有明显改变 loss 曲线的整体形态。较高学习率 5e-4 在最终 loss 和后期平均 loss 上略低，但优势并不大。

从生成样例和 FID 来看，1e-4 的 FID 最低，为 342.1240，说明它生成的样例与真实水墨图像集的特征分布更接近。5e-4 的 FID 为 386.7016，优于 2e-4 的 395.1786，但高于 1e-4。结合样例图观察，1e-4 的整体色调和水墨氛围较稳定；5e-4 虽然 loss 略低，但部分样例中局部色彩和元素表达更强，生成效果不一定更均衡。

## 4.5.3 对学习率影响的真实分析

根据上述真实数据，本文认为学习率对当前大训练集 LoRA 微调训练表现的影响可以概括为以下几点。

首先，在 1e-4、2e-4 和 5e-4 三组学习率下，模型都能够稳定完成 1200 步训练，最终 loss 和最低 loss 的差距都很小，说明当前训练设置对这一区间内的学习率具有一定鲁棒性。

其次，如果只看训练 loss，5e-4 的最终 loss 和后 100 步平均 loss 略低，可以说明较高学习率在当前训练长度内具有稍快的优化速度。但这种差距很小，不足以单独作为选择最优学习率的依据。

再次，如果结合 FID 和生成样例进行判断，1e-4 的综合表现更好。它虽然最终 loss 不是最低，但 FID 明显低于另外两组，生成图像在水墨色调、整体氛围和风格稳定性方面更接近真实训练集。

总体来看，在当前 2192 张图像的大训练集、Rank=16、训练 1200 步的实验条件下，1e-4 更适合作为本文学习率消融实验中的较优选择；5e-4 可带来略低的训练 loss，但生成质量并未同步体现出优势；2e-4 表现居中，但从本组 FID 结果看不如 1e-4 稳定。
